# Excel File Format Guide for Result Analyzer

## Required Excel File Structure

The Result Analyzer system requires Excel files to be formatted in a specific way to properly recognize course codes and process student marks.

## Sheet Structure
Your Excel file should contain separate sheets for:
- "UT 1" or "UT1" - Unit Test 1 results
- "UT 2" or "UT2" - Unit Test 2 results  
- "SEMESTER" or "SEM" - Semester exam results

## Column Headers Format
The system uses a regex pattern to extract course codes from column headers. The pattern looks for formats like:
- 22SVA4XX (digits + letters + alphanumeric mix)
- CS432 (letters + digits)
- EC284 (letters + digits)
- MAT264 (letters + digits)

## Required Columns
- Column A: SNO (Serial Number)
- Column B: REG NO (Student Registration Number)
- Column C: NAME (Student Name)
- Columns D+ : Course columns with course codes in the header

## Example Header Row Format
Row 1 should contain headers like:
| SNO | REG NO | NAME | 22CSE432 - DATA STRUCTURES | 22CSE234 - DIGITAL SIGNAL PROCESSING | 18CSE573 - DATABASE MANAGEMENT SYSTEMS | ... |

## Special Mark Values
- Empty cells or "0" = Student scored 0 marks
- "-" (hyphen) = Student not enrolled in this course
- "a" or "A" or "absent" = Student was absent, recorded as 0 marks

## Student Data
Starting from Row 2, enter student data:
- Column B: Registration numbers (e.g., 2303717710421047, etc.)
- Column C: Student names
- Columns D+: Marks for each course

## Example Row Data
| 1 | 91815901 | AASHISH M | 75 | 82 | 78 | ... |
| 2 | 91815902 | BARANI S | 80 | 75 | 85 | ... |

## Important Notes
1. Course codes in Excel headers must exactly match those in the database
2. For UT1 and UT2 sheets: Only theory and extra courses are processed
3. For SEMESTER sheet: All course types (theory, practical, extra) are processed
4. Marks for UT1/UT2 below 30 are considered failures
5. Marks for SEMESTER below 5 are considered failures (grade points)
6. The system calculates GPA automatically for semester results
